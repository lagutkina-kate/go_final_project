# Планировщик задач

Веб-приложение для управления задачами.

Приложение позволяет создавать, изменять и удалять задачи, получать данные по конкретной задаче, отмечать задачи выполненными и просматривать список задач из базы данных.

## Стек

- Go 1.26.1
- SQLite
- Docker

## Возможности

- Добавление новых задач
- Редактирование существующих задач
- Удаление задач
- Получение задачи по идентификатору
- Просмотр списка задач
- Отметка задачи как выполненной

## Команды

### Запуск тестов

```bash
make test
```

Команда собирает приложение, запускает локальный сервер на порту `7540`, выполняет тесты и останавливает сервер после завершения.

### Запуск Docker-контейнера

```bash
make docker-run
```

Команда собирает Docker-образ и запускает контейнер `go-final-project` на порту `7540`.
